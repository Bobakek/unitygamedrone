# Nova Frontier

Браузерная 3D космическая MMO: полёты между планетами, бои с пиратами и другими игроками,
**бесшовная высадка** на процедурно генерируемые планеты с выходом пилота на поверхность.

- **Клиент:** Three.js + TypeScript (Vite). Всё процедурное — ни одного файла моделей, текстур или звуков.
- **Сервер:** Node.js + WebSocket (`ws`), авторитетная симуляция 30 Гц, пилоты в SQLite (`node:sqlite`).
- **Общий код** (`src/shared`) — детерминированные шум, генерация систем, рельеф, физика корабля и пилота,
  бинарный протокол. Один и тот же код работает на сервере и в браузере (предсказание + сверка).

## Быстрый старт

Нужен Node.js ≥ 22.12.

```bash
npm install
npm run dev          # сервер :8080 (dev-команды включены) + Vite :5173
```

Откройте http://localhost:5173, введите позывной — и в полёт. Второй игрок — ещё одна вкладка
с другим позывным.

Продакшен-сборка (сервер раздаёт собранный клиент):

```bash
npm run build
npm start            # http://localhost:8080
```

Переменные окружения сервера: `PORT` (8080), `DB_PATH` (`data/pilots.db`), `DEV=1` — dev-команды в чате,
`CLIENT_DIR` (`dist/client`).

Качество графики выбирается на экране входа и в игре (`O` — настройки): **Низкое / Среднее / Высокое / Ультра**
(разрешение, сглаживание, свечение, тени, отражения, облака, трава, дальность детализации рельефа).
Там же чувствительность мыши и громкость. Можно передать `?q=low|medium|high|ultra`.

### Одиночный режим без сервера

```bash
npm run build:offline    # dist/offline — статические файлы, игровой сервер работает внутри страницы
```

Сборку можно выложить на любой статический хостинг. В обычной сборке тот же режим включается `?offline=1`.
Прогресс хранится в localStorage, dev-команды включены.

## Управление

| Полёт | |
|---|---|
| Мышь | курс (клик по экрану захватывает мышь, `Z` — отпустить) |
| `W` / `S`, колесо | тяга, `X` — стоп |
| `A` / `D`, `Space` / `C` | стрейф в стороны, вверх/вниз |
| `Q` / `E` | крен |
| `Shift` | форсаж, `J` — круизный двигатель (до 3 км/с, не работает у планет и станции) |
| `ЛКМ` | лазеры, `ПКМ` (удерживать на цели) — захват и пуск ракеты |
| `T` | выбрать цель, `Tab` — навигационная цель |
| `F` | стыковка со станцией / прыжок во вратах / разбор обломков |

| Планета | |
|---|---|
| Посадка | у поверхности сбросьте тягу (`X`) — корабль сам плавно опустится и сядет |
| `G` | выйти из корабля / сесть обратно |
| `WASD`, `Shift` | ходьба / бег |
| `Space` | прыжок, удерживать — джетпак |
| `ЛКМ` | ручной бластер (при захваченной мыши) |
| `F` | собрать ресурс (руда, кристаллы, реликты — светящиеся маяки), тайник в руинах, биообразцы с туши |

`Enter` — чат, `H` — справка, `O` — настройки. На станции: продажа груза, ремонт, ракеты, улучшения
(лазеры, щиты, броня, двигатель, трюм). Награда за сбитых пиратов.

## Что внутри

- **Галактика** из 3 звёздных систем (по seed): звезда, 4–6 планет семи типов (земная, океаническая,
  инопланетная, пустынная, ледяная, лавовая, безжизненная), станция, пояса астероидов, врата прыжка.
  Каждая система — отдельный инстанс на сервере.
- **Бесшовные планеты:** куб-сфера из 6 граней, у каждой quadtree LOD (чанки 16×16, до ~2 м у земли),
  генерация мешей в пуле Web Workers, отсечение по горизонту, «юбки» против трещин. Рельеф и биомы —
  одна функция `heightAt`/`surfaceColor`, сервер использует её же для столкновений и посадки.
- **Поверхность:** биомы и слои породы на скалах, кратеры на безвоздушных и ледяных мирах, море с видимым дном
  и гранёными волнами (лава светится, лёд — сплошной), низкополигональные кучевые облака, дрейфующие вокруг планеты.
  Два яруса объектов, расставляемых в воркерах: деревья, пальмы, грибы, кактусы, ледяные шпили, базальтовые
  столбы, валуны (до ~600 м) и трава, цветы, камешки (до ~110 м). Растительность колышется на ветру,
  стволы и валуны твёрдые для пилота.
- **Вращение планет:** каждая планета крутится вокруг наклонённой оси (сутки 12–20 минут), поэтому
  над поверхностью бегут рассветы, закаты и ночи; в HUD — местное время. Рядом с планетой (ближе двух
  радиусов) корабль и пилот живут во вращающейся системе отсчёта планеты: посадка, стоянка и ходьба не
  «сносятся», а переходы между системами сохраняют мировую скорость. Ввод помечается временем, поэтому
  предсказание на клиенте совпадает с сервером и на границе систем.
- **События в системе:** сервер сам запускает и объявляет события (баннер в HUD, пункт в навигации Tab,
  метка на радаре). *Пиратский конвой* — медленный бронированный грузовик с тремя эскортами идёт через
  систему; атака на грузовик натравливает охрану, а уничтоженный грузовик рассыпает контейнеры с грузом
  (подбираются пролётом). *Обломки* — дрейфующий разбитый корабль: подлетите, сбросьте скорость и нажмите
  **F**, чтобы разобрать (реликты, кристаллы, кредиты; иногда там засада). *Аномалия* — светящееся поле:
  продержитесь внутри 8 секунд, чтобы просканировать и получить награду.
- **Фауна:** на живых мирах (земные, океанические, инопланетные, пустынные, ледяные) вокруг пилотов
  появляются стада мирных животных и хищники — по паре видов на биом (травники и клыкачи, прыгуны и жнецы,
  панцирники и скорпиды, мохначи и ледяные волки). Процедурные скелеты: четвероногие, шестиногие и
  двуногие с походкой, пасущимися головами и броском при атаке. Мирные разбегаются, хищники охотятся на
  пилотов пешком. У пилота — ручной бластер и прочность скафандра (восстанавливается вне боя); если она
  кончится, дрон вернёт пилота на корабль, но половина груза пропадёт. С туш берутся **биообразцы** (новый
  товар на станции).
- **Объекты на поверхности:** на каждой планете по seed стоят древние *руины* (колоннада, обелиск со
  светящимися знаками, тайники с реликтами — **F** пешком) и *пиратские базы* (стены, ангар, посадочная
  площадка, склад с добычей) под охраной трёх флак-турелей, которые обстреливают корабли в радиусе 1,5 км.
  Турели можно сбить лазерами и ракетами; за подавление всей базы — награда, через 10 минут турели
  восстанавливаются. Колонны и башни твёрдые для пилота, деревья внутри объектов не растут.
- **Атмосфера и свет:** fresnel-оболочки из космоса, небо с рассветами и закатами, день/ночь, туман,
  отражения неба и космоса (IBL), тени от кораблей, пилота, деревьев и рельефа, цветокоррекция и виньетка.
- **Пилот:** полный процедурный скелет (бёдра, корпус, голова, плечи/локти, колени/стопы) и смешивание
  анимаций: покой с дыханием, шаг, бег, прыжок, падение, джетпак с пламенем, приземление, добыча
  ресурса инструментом с лучом; шаги с пылью и звуком.
- **Масштабы:** планеты радиусом 3–7 км, орбиты 40–200 км. Мировые координаты в double,
  плавающее начало координат и логарифмический depth buffer.
- **Сеть:** клиент шлёт ввод 30 раз в секунду, сервер симулирует и рассылает бинарные снапшоты с
  зоной интереса. Свой корабль предсказывается и сверяется (детерминированная симуляция + переигровка
  неподтверждённого ввода), чужие интерполируются на 100 мс в прошлом. Бюджет ввода защищает от спидхака.
- **Бой:** лазеры (проверка попаданий на сервере), самонаводящиеся ракеты, щиты с регенерацией, корпус,
  безопасная зона станции, пираты-NPC (патруль → атака с упреждением → бегство), респаун на станции.

## Структура

```
src/shared   общий детерминированный код (генерация, рельеф, симуляция, протокол)
src/server   игровой сервер: main.ts, game/{game,system,session,npc}.ts, db.ts
src/client   клиент: game.ts, planet/ (LOD, воркеры, атмосфера, пропсы), entities/, world/, ui/, net/, player/
tests        vitest: ядро и интеграционные тесты сервера
e2e/run.mjs  Playwright: полёт, посадка, выход пилота, два игрока, бой, стыковка, прыжок
```

## Тесты

```bash
npm test             # unit + интеграция сервера (WebSocket-боты)
npm run typecheck
npm run build && npm run e2e   # скриншоты в e2e/out/
node e2e/visuals.mjs           # визуальный тур по типам планет → e2e/out/visuals/
```

## Dev-команды (при `DEV=1`)

`/tp <n>` — к планете n на орбиту, `/tp low<n>` — низко над поверхностью, `/land <n>` — посадка рядом с ресурсом
(у планетных целей можно добавить `dusk` или `night`: `/land 2 night`), `/tp ruin<n>` / `/tp base<n>` — к руинам или базе планеты n,
`/tp station|dock|field|gate|open`, `/event convoy|wreck|anomaly` (событие прямо перед кораблём),
`/fauna <вид 0–7> [дистанция]` (стадо рядом с пилотом), `/pirate`, `/god`, `/credits <n>`, `/system <n>`.
