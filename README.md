# Nova Frontier

Браузерная 3D космическая MMO: полёты между планетами, бои с пиратами и другими игроками,
**бесшовная высадка** на процедурно генерируемые планеты с выходом пилота на поверхность.

- **Клиент:** Three.js + TypeScript (Vite). Почти всё процедурное; готовые модели (ровер, залежи для вылазок,
  грузовик, шахтёр и каюта пилота с трофеями) собираются скриптами Blender (`tools/blender/build_rover.py`,
  `build_deposits.py`, `build_ships.py`, `build_cabin.py` → `src/client/assets/*.glb`); текстур и звуков нет.
- **Сервер:** Node.js + WebSocket (`ws`), авторитетная симуляция 30 Гц, пилоты в SQLite (`node:sqlite`).
- **Общий код** (`src/shared`) — детерминированные шум, генерация систем, рельеф, физика корабля и пилота,
  бинарный протокол. Один и тот же код работает на сервере и в браузере (предсказание + сверка).

## Быстрый старт

Нужен Node.js ≥ 22.12.

```bash
npm install
npm run dev          # сервер :8080 (dev-команды включены) + Vite :5173
```

Откройте http://localhost:5173, введите позывной — и в полёт. Второй игрок — ещё одна вкладка
с другим позывным.

Продакшен-сборка (сервер раздаёт собранный клиент):

```bash
npm run build
npm start            # http://localhost:8080
```

Переменные окружения сервера: `PORT` (8080), `DB_PATH` (`data/pilots.db`), `DEV=1` — dev-команды в чате,
`CLIENT_DIR` (`dist/client`).

Качество графики выбирается на экране входа и в игре (`O` — настройки): **Низкое / Среднее / Высокое / Ультра**
(разрешение, сглаживание, свечение, тени, отражения, облака, трава, дальность детализации рельефа).
Там же чувствительность мыши и громкость. Можно передать `?q=low|medium|high|ultra`.

### Одиночный режим без сервера

```bash
npm run build:offline    # dist/offline — статические файлы, игровой сервер работает внутри страницы
```

Сборку можно выложить на любой статический хостинг. В обычной сборке тот же режим включается `?offline=1`.
Прогресс хранится в localStorage, dev-команды включены.

## Управление

| Полёт | |
|---|---|
| Мышь | курс (клик по экрану захватывает мышь, `Z` — отпустить) |
| `W` / `S`, колесо | тяга, `X` — стоп |
| `A` / `D`, `Space` / `C` | стрейф в стороны, вверх/вниз |
| `Q` / `E` | крен |
| `Shift` | форсаж, `J` — круизный двигатель (до 3 км/с, не работает у планет и станции) |
| `ЛКМ` | лазеры, `ПКМ` (удерживать на цели) — захват и пуск ракеты |
| `T` | выбрать цель, `Tab` — навигационная цель |
| `F` | стыковка со станцией / прыжок во вратах / разбор обломков |

| Планета | |
|---|---|
| Посадка | у поверхности сбросьте тягу (`X`) — корабль сам плавно опустится и сядет |
| `G` | выйти из корабля / сесть обратно |
| `WASD`, `Shift` | ходьба / бег |
| `Space` | прыжок, удерживать — джетпак; у препятствия до ~3 м — залезть на него и перелезть; в воде — всплыть |
| `C` | в воде — нырнуть (под водой `W` плывёт туда, куда смотрит камера) |
| колесо мыши | дистанция камеры (1,6–8 м) |
| `V` | светофильтр шлема: авто → поднять/опустить → авто |
| на бегу в низкий камень | перепрыгнуть с опорой на руку (автоматически) |
| `ЛКМ` / `ПКМ` | выстрел из бластер-винтовки (при захваченной мыши) / прицелиться через плечо |
| `F` | собрать ресурс (руда, кристаллы, реликты — светящиеся маяки), тайник в руинах или обломках, биообразцы с туши, разобрать сбитого дрона, прочитать бортовой журнал у пульта на мостике обломков |

| Ровер | |
|---|---|
| `R` | пешком у севшего корабля — выгрузить ровер, ещё раз — погрузить обратно в трюм |
| `G` | рядом с ровером — сесть за руль / выйти |
| `W` / `S` | газ / тормоз, на месте `S` — задний ход |
| `A` / `D` | руль |
| `Space` | ручник (задние колёса) |
| `Shift` | ускорение (до ~80 км/ч вместо ~58) |
| `R` | за рулём или рядом с перевёрнутым ровером — поставить его на колёса |
| `F` | у залежи (стоя на месте) — бурить; добыча едет в кузове ровера |
| мышь, колесо | обзор вокруг ровера, дистанция камеры |

| Станция | |
|---|---|
| `G` | в доке — выйти из корабля в ангар (или кнопка «Выйти на станцию»), у корабля — сесть обратно |
| `WASD`, `Shift`, `Space` | ходьба, бег, прыжок по палубе |
| `F` | у терминала: торговля и ремонт, улучшения, контракты, гардероб; в каюте — коллекция трофеев |
| `Esc` | закрыть окно терминала |

`Enter` — чат, `H` — справка, `O` — настройки. На станции: **рынок** (продажа и покупка груза), ремонт,
ракеты, улучшения (лазеры, щиты, броня, двигатель, трюм), **контракты** и гардероб — из окна стыковки или
с терминалов на променаде. Награда за сбитых пиратов. `P` — позвать в группу пилота-цель (или того, кто
рядом), `Y`/`N` — ответить на приглашение; в чате `/invite имя`, `/leave`, `/kick имя`, `/group`, `/g текст`.

## Что внутри

- **Галактика** из 3 звёздных систем (по seed): звезда, 4–6 планет семи типов (земная, океаническая,
  инопланетная, пустынная, ледяная, лавовая, безжизненная), станция, пояса астероидов, врата прыжка.
  Каждая система — отдельный инстанс на сервере.
- **Бесшовные планеты:** куб-сфера из 6 граней, у каждой quadtree LOD (чанки 16×16, до ~2 м у земли),
  генерация мешей в пуле Web Workers, отсечение по горизонту, «юбки» против трещин. Рельеф и биомы —
  одна функция `heightAt`/`surfaceColor`, сервер использует её же для столкновений и посадки.
- **Поверхность:** биомы и слои породы на скалах, кратеры на безвоздушных и ледяных мирах, низкополигональные
  кучевые облака, дрейфующие вокруг планеты; лава светится, замёрзшее море — сплошной лёд, по нему можно ходить.
  Два яруса объектов, расставляемых в воркерах: деревья, пальмы, грибы, кактусы, ледяные шпили, базальтовые
  столбы, валуны (до ~600 м) и трава, цветы, камешки (до ~110 м). Растительность колышется на ветру,
  стволы и валуны твёрдые для пилота.
- **Вращение планет:** каждая планета крутится вокруг наклонённой оси (сутки 12–20 минут), поэтому
  над поверхностью бегут рассветы, закаты и ночи; в HUD — местное время. Рядом с планетой (ближе двух
  радиусов) корабль и пилот живут во вращающейся системе отсчёта планеты: посадка, стоянка и ходьба не
  «сносятся», а переходы между системами сохраняют мировую скорость. Ввод помечается временем, поэтому
  предсказание на клиенте совпадает с сервером и на границе систем.
- **Ровер:** модель из Blender (`tools/blender/build_rover.py`, ~39 тыс. треугольников): рама с дугами
  безопасности, независимая подвеска на двойных рычагах с амортизаторами, поворотные кулаки, колёса с
  грунтозацепами, антенна-тарелка, маячок, фары и пилот за рулём. Каждая подвижная часть — отдельный узел,
  игра анимирует их по физике. Физика (`src/shared/sim/rover.ts`) — твёрдое тело на четырёх лучевых колёсах:
  пружина и демпфер в каждой стойке, круг трения (сцепление зависит от биома: лёд скользит, песок хуже травы),
  привод и тормоза, ручник, крен и опрокидывание на склонах, удары о деревья, брод и плавание в воде.
  Та же функция работает на сервере и в предсказании клиента. Пересобрать модель:
  `pip install bpy` и `python tools/blender/build_rover.py` (`--render out.png` — превью в Cycles).
- **Вылазки на ровере:** на каждой планете в километре-двух друг от друга лежат залежи, которые пешком
  не добыть: рудные жилы, кристаллические жеоды, метеориты, упавшие зонды и окаменелости (что где
  встречается, зависит от типа планеты). Сканер ровера показывает три ближайшие в навигации (⛏, `Tab`)
  и на радаре, над каждой стоит световой столб. Остановитесь рядом и нажмите `F`: бур за кормой ровера
  уходит в грунт, через 5 секунд добыча (руда, кристаллы, реликты, биообразцы, от 3 до 14 единиц)
  оказывается в кузове (24 места). Когда ровер грузят в корабль, кузов разгружается в трюм, а груз
  продаётся на рынках станций. Выработанная залежь гаснет у всех и восстанавливается через 30 минут.
  Модели залежей — `tools/blender/build_deposits.py`, правила — `src/shared/planet/deposits.ts`.

  ![Пять видов залежей: рендер Blender](docs/screenshots/deposits-blender.png)
- **Каюта пилота:** дверь в задней стене променада, слева от шлюза, ведёт в свою каюту — она есть на каждой
  станции, и в ней видны только трофеи того, кто стоит внутри (пилоты в каютах друг друга не видят). Трофеи
  появляются сами и хранятся вместе с пилотом: первый реликт из тайника каждых руин, базы или обломков — на полку,
  бортовой журнал, прочитанный на мостике разбитого корабля, — в стойку над столом (из коллекции его можно
  перечитать), первые биообразцы нового вида — банка в шкафу, первая аномалия в системе — светящийся осколок,
  нашивки на стенде — за 1, 10, 25, 50, 100 и 250 сбитых кораблей и за каждое звание, медали в витрине — за
  репутацию «Друг» и «Союзник» у фракций. Терминал «Коллекция» у двери показывает всё с датами. Комната,
  мебель и модели трофеев собираются в Blender (`tools/blender/build_cabin.py`); места на полках — пустые
  объекты `Slot_*` в той же модели, игра расставляет по ним последние трофеи и перекрашивает их.
- **События в системе:** сервер сам запускает и объявляет события (баннер в HUD, пункт в навигации Tab,
  метка на радаре). *Пиратский конвой* — медленный бронированный грузовик с тремя эскортами идёт через
  систему; атака на грузовик натравливает охрану, а уничтоженный грузовик рассыпает контейнеры с грузом
  (подбираются пролётом). *Обломки* — дрейфующий разбитый корабль: подлетите, сбросьте скорость и нажмите
  **F**, чтобы разобрать (реликты, кристаллы, кредиты; иногда там засада). *Аномалия* — светящееся поле:
  продержитесь внутри 8 секунд, чтобы просканировать и получить награду.
- **Фауна** (процедурные скелеты с челюстью: шаг, рысь и галоп, разворот на месте, выпас, стойка
  «настороже», лёжка, укус и бросок, прыжок-наскок, удар передними лапами или жалом, рык, гибель):
  на живых мирах (земные, океанические, инопланетные, пустынные, ледяные) вокруг пилотов
  появляются стада мирных животных и хищники — по паре видов на биом (травники и клыкачи, прыгуны и жнецы,
  панцирники и скорпиды, мохначи и ледяные волки). Процедурные скелеты: четвероногие, шестиногие и
  двуногие с походкой, пасущимися головами и броском при атаке. Мирные разбегаются, хищники охотятся на
  пилотов пешком. У пилота — ручной бластер и прочность скафандра (восстанавливается вне боя); если она
  кончится, дрон вернёт пилота на корабль, но половина груза пропадёт. С туш берутся **биообразцы** (новый
  товар на станции).
- **Объекты на поверхности:** на каждой планете по seed стоят древние *руины* (колоннада, обелиск со
  светящимися знаками, тайники с реликтами — **F** пешком) и *пиратские базы* (стены, ангар, посадочная
  площадка, склад с добычей) под охраной трёх флак-турелей, которые обстреливают корабли в радиусе 1,5 км.
  Турели можно сбить лазерами и ракетами; за подавление всей базы — награда, через 10 минут турели
  восстанавливаются. Колонны и башни твёрдые для пилота, деревья внутри объектов не растут.
- **Вода:** прозрачное море, цвет и прозрачность которого зависят от глубины (бирюзовое мелководье с видимым
  дном → синяя глубина), зыбь и рябь, отражения неба по Френелю, прибой: волны и линии пены бегут к берегу,
  барашки на гребнях, свет сквозь гребни; снизу — окно Снелла. На дне — анимированные каустики.
- **Плавание и ныряние:** в глубокой воде пилот плывёт (кроль на поверхности, брасс или зависание под водой),
  `C` — нырнуть, под водой `W` плывёт по направлению взгляда, `Space` — вверх; механика общая для клиента и
  сервера. В скафандре 75 с воздуха (шкала в HUD), без воздуха скафандр теряет прочность. Под водой —
  бирюзовая дымка, темнеющая с глубиной, лучи солнца, взвесь планктона, пузыри из шлема, приглушённый звук.
- **Морская жизнь:** на дне растут ламинария, ветвистые, трубчатые и «мозговые» кораллы, анемоны, морские
  звёзды и ракушки; над ними кружат косяки рыб (разбегаются от ныряльщика) и светящиеся ночью медузы — всё
  по seed планеты, одинаково у всех игроков. Серверные морские существа: мирные *скат-парусник* и
  *светокрыл* уплывают от ныряльщиков, хищные *пилозуб* и *угреглот* нападают на пилотов в воде; туши
  всплывают, с них берутся биообразцы.
- **Атмосфера и свет:** fresnel-оболочки из космоса, небо с рассветами и закатами, день/ночь, туман,
  отражения неба и космоса (IBL), тени от кораблей, пилота, деревьев и рельефа, цветокоррекция и виньетка.
- **Пилот:** полный процедурный скелет (бёдра, корпус, голова, плечи/локти, колени/стопы) и смешивание
  анимаций: покой с дыханием и жестами (осмотреться, взглянуть на наручный компьютер, потянуться), шаг,
  бег, бег назад и вбок с диагоналями, поворот на месте, прыжок, падение, джетпак, приземление,
  перепрыгивание препятствий с опорой на руку, залезание на стены, карабканье по крутым склонам,
  вздрагивание от ран, добыча ресурса инструментом с пояса. **Бластер-винтовка** висит за спиной и
  вскидывается к плечу при прицеливании и стрельбе: обе руки держат её через IK, есть отдача и вспышка,
  болты вылетают из ствола — и у других игроков тоже.
- **Скафандр в духе NASA EMU/xEMU:** жёсткая верхняя часть с кольцами-подшипниками (шея, плечи, пояс),
  нагрудный пульт с кнопками, экраном и именем пилота, шланги к ранцу жизнеобеспечения (решётки, поручни,
  антенна), гофры на локтях и коленях, кольца на запястьях и лодыжках, перчатки с пальцами, ботинки с толстой
  подошвой, флаг и эмблема на плечах. Шлем-пузырь под щитком с фонарями; золотой светофильтр сам опускается
  днём и поднимается в темноте или под водой — за стеклом видно лицо в шлемофоне (`V` — вручную). Все
  непрозрачные детали сустава — один меш с одним материалом (цвет, шероховатость и металличность по вершинам,
  мелкое плетение ткани), геометрия кэшируется по наряду.
- **Гардероб и экипировка** (станция → «Гардероб пилота»): 3D-превью с примеркой, вкладки по слотам, покупка
  за кредиты, стартовый комплект бесплатно; наряд сохраняется в профиле и виден другим игрокам. Расцветки
  (белый, командирский с красными полосами, оранжевый ACES, «Орлан», песчаный, графитовый), шлемы (купол,
  панорамный, бронешлем +10), светофильтры (золото, серебро, янтарь, хамелеон, прозрачный), ранцы
  (кислородные баллоны — 150 с воздуха вместо 75, усиленный джетпак — расход топлива −40 %, ремонтный
  модуль — самопочинка 10 ед./с), грудь (бронепластина +30, разгрузка — +1 биообразец), EVA-фонари
  (ночью светят по-настоящему), шесть нашивок. Свойства считаются одинаково на сервере и в предсказании.
  За репутацию у фракций продаются их скафандры и снаряжение: «Флотский» и щит «Эгида» (+45) Федерации,
  «Старательский» и глубоководный ранец (240 с воздуха) Гильдии, «Рейдер» и форсажный ранец (расход
  топлива 0,2) Синдиката.
- **Контракты, фракции, звания** (станция → «Контракты»). Доска заданий своя у каждой станции и обновляется
  каждые 10 минут (одинаковая для всех пилотов системы):
  - *Гильдия старателей* — охота на хищников конкретного вида на планете, поставка руды, кристаллов,
    реликтов или биообразцов на станцию, доставка груза на станцию другой системы, разведка руин и
    обломков пешком;
  - *Федерация* — охота на пиратов, зачистка турелей пиратской базы, перехват идущего через систему конвоя
    (предложение появляется вместе с конвоем и снимается, если он ушёл);
  - *Синдикат «Чёрная звезда»* (теневые предложения) — контрабанда реликтов и кристаллов на пиратскую базу.

  Цель засчитывается сразу (поставки — при стыковке, можно частями): кредиты, опыт и репутация. Активные
  контракты видны под панелью пилота, их цели — ромбами в навигации (`Tab`) и на радаре; для другой системы —
  нужные врата. Звания (Курсант → Пилот → Лейтенант → Капитан → Командор → Адмирал) открывают задания
  выше уровнем и больше одновременных контрактов. Репутация (Враг · Недруг · Нейтралитет · Друг · Союзник)
  меняется и от поступков: сбитый пират — Синдикат −2, Федерация +1; турель — Синдикат −4; контрабанда —
  Федерация −8. Друзей Синдиката пираты и турели не трогают первыми, пока те сами не начнут стрелять по
  пиратам; пилот с репутацией Федерации ниже −25 объявляется в розыск — его видно всем, а за его корабль
  положена награда +200 кр.
- **Рынки станций** (станция → «Рынок»). Каждая система ценит товары по-своему, и всё выводится из её
  генерации: где много лавовых и безвоздушных миров и астероидных полей — дешёвая руда, где ледяные и
  инопланетные — кристаллы, где живые миры — биообразцы, где больше руин и обломков — реликты. Системы
  ранжируются друг против друга (сколько бы их ни было): самые богатые товаром платят за него ×0,7 и
  **продают** его (на 20 % дороже своей скупки), самые бедные платят ×1,4. Цены дрейфуют каждые 10 минут
  (±12 %, одинаково у всех) и отвечают на торговлю: каждая проданная единица сбивает цену на 1,5 %, купленная
  поднимает, эффект тает с полупериодом 8 минут. В окне станции — таблица: что в трюме, почём здесь
  скупают и продают, и сколько платят в системах за вратами (лучшая цена зелёная, ⇄ — там продают).
  Так появляется торговля: купить биообразцы на живом мире, отвезти туда, где их нет.
- **События в галактике.** Раз в несколько минут где-то в галактике что-то случается (обычно идут 2–3
  события сразу, по 12–26 минут): **пиратский набег** на станцию (чаще в пограничье и на рубеже), **метеоритный
  шторм**, **дефицит** товара. Расписание считается из реального времени, поэтому события идут и в спящих системах:
  меняются цены (набег: всё ×1,25; шторм: руда ×1,6 и кристаллы ×1,5; дефицит: товар ×2 и ×1,25 у соседей) и на
  досках появляются срочные контракты («Отбить набег на станцию», ремонт станции и срочная доставка у соседей,
  руда для щитов в шторм). Если в системе кто-то летает, событие происходит по-настоящему: налётчики волнами
  кружат у подходов к станции, метеориты бьют по кораблям в открытом космосе и оставляют осколки с рудой и
  кристаллами. Новости приходят в чат всем пилотам, значки событий видны на карте галактики (M), а в окне рынка
  написано, что творится здесь и за вратами.
- **Группы пилотов** (до 5). Пригласить — `P` на цели или рядом, или `/invite имя`; принять — `Y` или кнопка
  в панели. Панель группы под панелью пилота: где каждый (дистанция, система, «на станции», «сбит») и
  корпус; союзники на радаре и в метках — зелёные, в навигации (`Tab`) — «Группа: имя». Своих не
  задеть: ни лазер, ни ракета не наносят урона союзнику, а ракета его и не захватывает. Награда за пирата, турели базы, разыскиваемого пилота
  делится поровну между членами группы ближе 5 км, и за каждого лишнего пилота к общей сумме +15 %;
  зачёт по контрактам на охоту, пиратов, зачистку и перехват получают все они. `/g` — чат группы.
  Группа живёт, пока её участники онлайн; если лидер выходит, лидером становится следующий.
- **Погода и опасная среда.** У каждой планеты своё расписание погоды (окна по 5 минут, буря примерно в
  половине из них, нарастает и стихает по 40 с), одинаковое на сервере и у всех клиентов. Буря зависит от
  типа мира:

  | Планета | Буря | Чем опасна |
  |---|---|---|
  | земная, океаническая | гроза: ливень, ветер 14 м/с | молнии бьют рядом с пилотами, ближе 5 м — 30 урона |
  | ледяная | метель, видимость 70 м | холод 2,5/с |
  | пустынная | песчаная буря, видимость 50 м, ветер 20 м/с | абразия 2/с |
  | инопланетная | кислотный дождь | кислота 2,5/с |
  | лавовая | пеплопад и жара | жара 2,5/с, у лавы слабый жар и в ясную погоду |
  | безвоздушная | радиационная буря | радиация 3,5/с, только на дневной стороне |

  Ветер сносит пилота: на земле слегка, в прыжке и на джетпаке заметно; эта механика общая для сервера и
  предсказания. Буря видна и слышна: частицы, вытянутые по ветру, туман цвета бури, тёмное небо, вспышки и
  разряды молний, гром с запаздыванием по дальности, вой ветра, шум дождя, треск счётчика Гейгера, дрожание
  воздуха от жары. В HUD — значок угрозы с уроном и защитой, в панели пилота — прогноз («метель через 1:40»).
  Укрыться можно в корабле, внутри обломков или под водой (от холода вода не спасает). Защищает новый слот
  гардероба **«Модуль защиты»** — баллончик с огоньком на поясе: «Термослой» (холод и жара, 85 %),
  «Фильтры» (песок и кислота, 85 %), «Радиационный экран» (85 %), «Странник» Гильдии (всё по 60 %).
- **Разбившиеся корабли.** На каждой планете лежат 1–2 обломка (на враждебных мирах — два): корпус 72 м с
  рёбрами, вмятинами и копотью, оторванная корма, борозда в грунте. Внутрь можно войти через корму или
  пробоину в борту и пройти по коридору мимо кают и грузового трюма к мостику. Внутри темно: свет только из
  пробоин, аварийные лампы, зелёное свечение реактора, фонари скафандра включаются сами. Есть потолок, а на
  крышу можно запрыгнуть сверху. В трюме и каютах — тайники с реликтами и кристаллами. В реакторной утечка
  радиации (нужен экран). На мостике — **бортовой журнал**: кто летел, что случилось и чем кончилось (`F` у
  пульта). Обломки охраняют **дроны-стражи**: патрулируют отсеки, видят пилота до 24 м и только по прямой
  видимости (стены закрывают), стреляют красными болтами; сбитого дрона можно разобрать на кристаллы и
  кредиты. Гильдия даёт контракт «Разведка обломков» — добраться до мостика.
- **Станция изнутри.** В доке камера показывает ангар с вашим кораблём на площадке. `G` — выйти по трапу в
  ангар: силовое поле ворот, ящики, кран, диспетчерская над шлюзом. Через шлюз с раздвижными дверями —
  **променад**: огромные окна в настоящий космос (планета, звезда, пролетающие корабли; внешний корпус
  станции, пока вы внутри, скрыт), растения, скамейки, голограмма системы с планетами на орбитах и четыре
  терминала («F»): торговля и ремонт, улучшения, контракты, гардероб. Другие пилоты на станции ходят рядом
  (их видят только те, кто сам на станции), над головой у них 6 секунд висят реплики из чата — это работает
  и на планетах. Палуба симулируется на сервере, как и ходьба по планете (свой режим, протокол 7).
- **Лаборатория анимаций** (кнопка на экране входа или `?lab`): пилот и все 12 видов существ, каждый клип
  отдельно (включая трассы с препятствиями и склоном и бассейн для плавания и морских видов), скорость
  воспроизведения, пауза и покадровый шаг, наклон прицела, строй «все существа», листы кадров для сравнения.
- **Камера пешком** — низкая, из-за правого плеча, не поднимается высоко при взгляде вниз, подъезжает ближе,
  если сзади склон, колесо меняет дистанцию; ныряет вместе с пловцом.
- **Земля под ногами:** деревья, камни, узлы ресурсов, постройки, пилоты, существа и посаженные корабли
  прижимаются к рельефу в том виде, в каком он сейчас нарисован (дальний рельеф — упрощённый LOD), так что
  ничего не висит в воздухе и не проваливается при смене детализации.
- **Корабли:** на верфи станции три класса (`src/shared/ships/hulls.ts`). Истребитель «Стриж» есть у всех.
  Грузовик «Тягач» (3800 кр): трюм 60 (+22 за уровень), броня ×1,7, но скорость ×0,62, повороты ×0,5 и пушки
  ×0,55. Шахтёр «Крот» (2600 кр): трюм 30 (+14 за уровень) и буровые лазеры на стрелах. Купленный корабль
  ждёт в ангаре любой станции, пересесть можно при стыковке, если груз помещается в трюм. Улучшения
  принадлежат пилоту и действуют на любом корабле. Модели грузовика (~19 тыс. треугольников: мостик,
  двенадцать контейнеров в рамах, турель, четыре сопла, радиаторы) и шахтёра (~17 тыс.: стрелы с
  излучателями, бункер с рудой, баки) собирает `tools/blender/build_ships.py`; игра красит корпус в цвета пилота.
- **Добыча астероидов:** лазеры шахтёра упираются в астероиды и бурят их: каждые 55 единиц урона дают
  единицу руды или кристаллов (каждый пятый астероид кристаллический) прямо в трюм. Астероид отдаёт 3–16
  единиц в зависимости от размера и восстанавливает по одной за 90 секунд, поэтому шахтёр переходит от
  камня к камню. Добычу считает сервер (`src/server/game/mining.ts`).
- **Масштабы:** планеты радиусом 3–7 км, орбиты 40–200 км. Мировые координаты в double,
  плавающее начало координат и логарифмический depth buffer.
- **Сеть:** клиент шлёт ввод 30 раз в секунду, сервер симулирует и рассылает бинарные снапшоты с
  зоной интереса. Свой корабль предсказывается и сверяется (детерминированная симуляция + переигровка
  неподтверждённого ввода), чужие интерполируются на 100 мс в прошлом. Бюджет ввода защищает от спидхака.
- **Бой:** лазеры (проверка попаданий на сервере), самонаводящиеся ракеты, щиты с регенерацией, корпус,
  безопасная зона станции, пираты-NPC (патруль → атака с упреждением → бегство), респаун на станции.

## Структура

```
src/shared   общий детерминированный код (генерация, рельеф, симуляция, протокол)
src/server   игровой сервер: main.ts, game/{game,system,session,npc,contracts}.ts, db.ts
src/client   клиент: game.ts, planet/ (LOD, воркеры, атмосфера, пропсы), entities/, world/, ui/, net/, player/
tests        vitest: ядро и интеграционные тесты сервера
e2e/run.mjs  Playwright: полёт, посадка, выход пилота, два игрока, бой, стыковка, гардероб, контракты, прогулка по станции, прыжок
e2e/visuals.mjs  визуальный тур: типы планет, «прижатость» объектов к рельефу, вода и подводная жизнь, события, объекты, фауна, ночь,
             бури (node e2e/visuals.mjs weather), обломки (wreck), станция изнутри (station)
e2e/anim-lab.mjs листы кадров лаборатории анимаций и монтаж клипов пилота
e2e/trade-groups.mjs рынок станции и группа из двух пилотов → e2e/out/trade/
e2e/ships.mjs  верфь, грузовик глазами другого пилота, бурение астероида → e2e/out/ships/
tools/blender  build_rover.py, build_ships.py: модели в Blender (bpy) → src/client/assets/*.glb
```

## Тесты

```bash
npm test             # unit + интеграция сервера (WebSocket-боты)
npm run typecheck
npm run build && npm run e2e   # скриншоты в e2e/out/
node e2e/visuals.mjs           # визуальный тур по типам планет → e2e/out/visuals/
node e2e/trade-groups.mjs      # рынок и группа в браузере → e2e/out/trade/
node e2e/ships.mjs             # верфь, грузовик, шахтёр → e2e/out/ships/
npm run anim                   # листы кадров анимаций → e2e/out/anim/
```

На медленном программном рендере e2e можно облегчить: `E2E_Q=low E2E_VIEWPORT=960x540 E2E_TIMEOUT=180000 node e2e/visuals.mjs`
(пресет графики, размер окна, таймаут шага в мс). На своём компьютере с видеокартой e2e идут на ней:
`E2E_GPU=1 npm run e2e` (`E2E_HEADED=1` — показать окно браузера); перед первым запуском —
`npx playwright install chromium`.

## Dev-команды (при `DEV=1`)

`/tp <n>` — к планете n на орбиту, `/tp low<n>` — низко над поверхностью, `/land <n>` — посадка рядом с ресурсом
(у планетных целей можно добавить `dusk` или `night`: `/land 2 night`), `/tp ruin<n>` / `/tp base<n>` — к руинам или базе планеты n,
`/tp wreck<n>` — к обломкам на планете n,
`/tp station|dock|field|rock|gate|open` (`rock` — носом к астероиду, для проверки бурения),
`/ship <fighter|hauler|miner>` — получить корабль и сразу пересесть, `/event convoy|wreck|anomaly` (событие прямо перед кораблём),
`/fauna <вид 0–12> [дистанция]` (стадо рядом с пилотом; 8–11 — морские, появляются в ближайшей воде, 12 — дроны-стражи),
`/weather <storm|blizzard|sandstorm|acid|ash|radiation|clear> [сила 0..1] [секунд]` — погода на планете пилота,
`/strike` — молния прямо в пилота (`/strike 1` — рядом), `/inside <hold|bridge|quarters|rad>` — пешком внутрь ближайших обломков,
`/deck <trade|upgrades|contracts|wardrobe|trophies|cabin|shelf|window|ramp>` — на палубе станции к терминалу, в каюту, к окну променада или трапу,
`/trophies` — наполнить каюту трофеями (реликты и журналы этой системы, все нашивки, медали, образцы),
`/tp beach [n]` / `/tp dive [n]` — на пляж у моря или под воду (планета n или первая с водой),
`/wear <id>` — надеть вещь без магазина (id из `src/shared/outfit.ts`), `/pirate`, `/god`,
`/credits <n>`, `/system <n>`, `/cargo <ore|crystal|relic|bio> <n>`; карьера: `/rep <fed|guild|pirate> <значение>`,
`/xp <n>`, `/contract <hunt|pirates|clear|intercept|supply|deliver|survey|smuggle>` (взять с текущей доски),
`/finish` (выполнить первый активный), `/career` (сбросить); `/gevent <raid|storm|shortage> [товар] [минут]` — событие
галактики в текущей системе прямо сейчас, `/gevent end` — снять.
